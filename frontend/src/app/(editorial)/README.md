# Editorial route group

This route group will contain public, indexable editorial experiences once their
content, sources, metadata, and artwork-media rights records pass validation.

Planned route families include:

- `epochen/`
- `werke/`
- `kuenstler/`
- `motive/`
- `techniken/`
- `vergleichen/`

Do not add placeholder `page.tsx` files. A route becomes public only when its owning
domain specification and publication gates are satisfied.
